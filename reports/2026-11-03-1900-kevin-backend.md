## What was implemented
- `backend/supabase/functions/answer/` — `POST /answer`, SSE (`meta` → `delta`* → `done`, or `error`). Request/response exactly as in the assignment; `meta` additionally carries `needs_confirmation` (confidence below `CONFIDENCE_THRESHOLD`, default 0.6 → streamed text is a 2–4 word confirmation question).
- `auto` mode, not addressed to the assistant: `meta{is_question:false}` immediately, upstream request aborted. Explicit modes (`push_to_talk`, `text`) always open the gate.
- `LLMProvider` interface (`answer/llm/types.ts`); implementations: `AnthropicProvider` (default model `claude-haiku-5-5`, official SDK), `MockProvider` (offline; only when `LLM_PROVIDER=mock`). The API key is read only from the Supabase secret `ANTHROPIC_API_KEY`.
- `POST /tts` — ElevenLabs TTS proxy (streams audio, characters metered; never Agents). Key in secret `ELEVENLABS_API_KEY`, voice in `ELEVENLABS_VOICE_ID`.
- Auth: Supabase anonymous sign-in; JWT verified in-function (JWKS or optional HS256 secret), `role=authenticated` + `sub` required; the anon/publishable key alone is rejected; gateway `verify_jwt=true` as well.
- Limits: body 16 KB and field caps (400/413); Postgres fixed-window limiter (`check_rate_limit`, atomic) — per user per minute and day, plus a **global daily kill switch**; TTS limits in characters. Limiter errors deny (fail closed).
- Cost measurement: every request writes tokens, timings and estimated USD cost (at the prices in the assignment) to `answer_usage`; also a JSON log line without user id or text. Transcripts/answers are never logged or stored.
- Fail closed: no key → 503 `provider_unconfigured`; Anthropic 402 or "credit balance" 400 → 503 `provider_quota`; ElevenLabs quota → 503 `provider_quota`; all carry `fallback:true` so the app uses Apple TTS / on-device answers.
- `backend/README.md`: deploy steps, secret names, curl + SSE example, TTFT script usage. `docs/DECISIONS.md` D20 added.

## Technical details
- Model wire format: first line JSON header (`is_question`, `reconstructed_question`, `confidence`), then the answer. Parsed incrementally (`parser.ts`), `meta` is emitted as soon as the header closes. A missing/invalid header fails safe (auto mode: no answer; explicit modes: text is the answer).
- First provider chunk is awaited before returning HTTP 200, so quota/auth errors are real HTTP errors, not stream errors.
- Haiku 5.5 request per the Claude API docs bundled with the claude-api skill (**verified in docs**): no `temperature`/`top_p`/`top_k`; `thinking:{type:"disabled"}` + `output_config.effort:"low"` for latency (accepted at effort ≤ high); `max_tokens` 256; streaming. Both thinking and effort are env-tunable (`LLM_DISABLE_THINKING`, `LLM_EFFORT`) in case measured quality is poor.
- Prompt is static and short; spoken text is stripped of `<`/`>` so it cannot forge data tags (prompt-injection hygiene). Prompt asks for ≤2 short sentences, numbers/units/years written as words (ElevenLabs Flash does not normalise), no markdown.
- Pinned deps: `@anthropic-ai/sdk@1.3.0`, `jose@5.9.6`, `@supabase/supabase-js@2.45.4`, `jsr:@std/assert@1.0.8`. (SDK 1.4.0 was < 24 h old and blocked by Deno's dependency-age policy; 1.3.0 is 10 days old.)

## Known bugs, limitations, risks
- Prompt quality is untested: confidence calibration (when to ask "Menar du…?"), the auto-mode `is_question` gate and Swedish number-word output need a run on real Claude and tuning on the 30 prompts + a few non-question utterances.
- Server-side TTFT excludes network and Edge Function cold start; expect extra 100–400 ms on the first call after idle (**untested assumption**). The app must measure end-to-end itself.
- Model must emit the header first; if Haiku ignores the format, auto mode answers nothing (by design) — watch the `header_parse_failed` log counter after first real runs.
- Supabase anonymous sign-in: IP limit 30/hour; Supabase recommends CAPTCHA (**verified in docs**). A cheap abuse path remains: creating many anonymous users multiplies per-user limits — the **global daily cap** (`ANSWER_GLOBAL_PER_DAY`, default 5000 ≈ well under one US dollar/day at Haiku prices if prompts stay ~1k tokens) is the real cost ceiling. Owner should still set a monthly spend limit in the Anthropic Console (auto-reload off) and disable overage billing on ElevenLabs.
- Free-tier Edge Function limits (invocations, wall-clock per request) not checked against Supabase's current docs; streaming answers are short so should fit (**untested assumption**).
- Price figures ($0.10/$0.50 per MTok ≤100k) come from the assignment and match the claude-api skill's cached table (2026-10-06); verify on the pricing page before relying on the cost estimate.
