## Addendum: questions about the user (owner request, D51)
Someone asking the user something about themselves ("vad har du gjort i sommar?", "var bor du?") is routed to the line route and answered **from `memories`** in first person with the question handed back: with memory "Åkte skidor i Åre i somras" -> "Jag åkte skidor i Åre, du då?"; with no memory the prompt gets an explicit `no_memory` signal and the line becomes "Inte så mycket, jag är mer intresserad av vad du har gjort." (verified live on v24; an earlier version invented "jobbade mest och hann med några dagar vid havet", which is why the signal exists). Never asks the other person to tell first. Same rule is in the Rizz prompt. Limit: with a vague memory ("Pluggar medicin") the model may still add a small detail ("inför tentorna").
