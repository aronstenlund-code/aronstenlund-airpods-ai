## What was done

### K1.1 Oral grading (`exam/spoken.ts`, `exam/handler.ts`)
- **New `spoken.ts`** reads numbers the way a student says them:
  - spoken decimals ("sexton komma fem" = 16.5);
  - fractions ("en halv", "tre fjärdedelar", "två och en halv");
  - a spoken minus ("x blir minus tre");
  - the final answer is the last number after the last "så / blir / är / = / lika med / svaret";
  - "7 = x", "x är sju" and "x = 7" all give 7, and a coefficient such as "3x" is never the answer.
- **`numericCheck` uses the new reader.** Integers must match exactly; otherwise the tolerance is max(0.005, 0.05 %). So "600,5" no longer counts as 600.
- **`correctPoints` corrects the model's points in code:**
  - a correct final number gives the answer point (taken from the scoring rule "+C för korrekt svar");
  - a wrong one never gets it, but a method point on the same level stays;
  - a bare wrong number ("500", "ungefär 16") gets 0 points.
- **Grade prompt:** a correct number gives the answer point; a bare number earns no method point; the feedback never claims something that is not in the answer.
- **Tests:** unit tests cover 30 spoken forms. The live check is `scripts/exam-grade-eval.py`: 30 cases over 7 tasks, result in `reports/eval/exam-grade-2026-11-08.md`, run twice, **30/30** both times.

### K1.2 Provläge never states its reasoning (`answer/speech.ts`, `answer/prompt.ts`)
- **New `isReasoningMeta`** reads a sentence by its meaning, not by one known phrase. It drops the sentence when it:
  - points at the input or the material ("i din lista", "ämnesord", "närliggande", "låter likt");
  - classifies a word by subject ("inte ett kemiord");
  - states an interpretation ("jag tar det som", "du menar", "jag tolkar").

  It works on every sentence in Provläge, not only the first, and the rest of the answer is kept.
- **"Subject first" rule:** a word that is itself a term in the profile's subject keeps that subject's meaning ("syntes" with Kemi = syntesreaktion, with Biologi = fotosyntes). The rule also forbids mentioning the list, the profile or the exam date as a reason.
- **Live evaluation:** 4 new `ämne` cases in `scripts/live-eval-cases.json`; `live-eval.py` now sends `prep_terms`.

### K1.3 Math level (`answer/mathcheck.ts`, `prompt.ts`, `speechsym.ts`)
- **Level rule:**
  - Åk 6–9 gets the idea of a derivative (rate of change, slope, speed), with no limit, "h går mot noll", f′ notation or rules;
  - equations are solved step by step;
  - Matte 3 gets the limit definition and the power rule;
  - Matte 4 also gets the chain, product and quotient rules and eˣ, ln, sin and cos.
- **Checked in code (`computeMath`):** the derivative of a polynomial and the solution of a linear equation, written or spoken ("derivera tre x i kvadrat plus två x minus fem" → 6x + 2; "två x plus nio är lika med tre" → x = −3). The result goes to the model as `<computed>`, and the model explains it at the student's level.
- **Root cause of "derivatan av x i kvadrat är två gånger":** the speech step read "2x" as "2 gånger". In maths ("=", powers, a bare x, an operator next to it) it is now read as "två x". "2x snabbare" is still "två gånger".
- **D87 bank:** 12 `mathlevel` cases for Åk 8, Matte 3c and Matte 4, so the bank now has 191 cases. Result: 9/12 "first answer enough", correct 83 %, natural 42 %, length 67 % (`reports/eval/provlage-2026-11-08-haiku-k13-mathlevel.md`). The misses are long answers that read formulas aloud. That is K2 work.

### K1.4 Förhör mig (`validate.ts`, `prompt.ts`, `handler.ts`)
- **New optional field `context.already_asked`** (up to 40) lists every check question asked in the session. It is merged with the questions found in `recent_qa`, because `recent_qa` holds only 6 turns.
- **No repeated question:** if the new question is almost one already asked (bigram similarity ≥ 0.8), it is generated again once. Nothing has reached the app at that point, because the quiz answer is held until it is complete.
- **New optional field `context.last_answer_age_sec`.** A short reply is graded as the answer only when:
  - it is not a question ("vad är mitos", "förklara …", or ending in "?");
  - and it comes within **120 s** of the check question. Without the field, the old rule holds.

### K1.5 Interview, facts missing from the CV (`answer/interviewfacts.ts`)
- **Detection:** code spots a question about körkort, age (in digits or words), alcohol or commuting when the CV part of `persona_setup` (never the job ad) and `memories` say nothing about it.
- **The model then gets a note:** never yes or no, never "har inte", no age, and nothing about where the user lives or how they travel. It answers with what the CV shows.
- **Filter:** a yes/no opening is dropped, and so is any sentence that still makes such a claim ("Jag bor i Malmö …").

### K1.6 Cut Social/Rizz suggestions (`answer/rizz.ts`, `personas.ts`)
- **Root cause:** when the stream stopped at the token cap, the last line was cut mid-word ("…ligga ner, Tal") and was still taken as a suggestion. The speaker-label filter had dropped the first line, so the model used up its tokens.
- **Fix:** a last line without a newline now counts only when it ends like a finished sentence.
- **Token cap:** raised to max(140, 60 + 35 per line), so a backup line fits after a dropped one. This does not change time to the first suggestion, because the preview goes out as soon as line 1 is complete.

### K1.7 Exam session (`exam/handler.ts`)
- **Tables:** parse writes every table value into the task text (row by row). Live on a synthetic page with two tables: 2/2 correct, about 0.0005 USD per page.
- **Summary:** the missing total is never smaller than the A or C/A points needed. When only A points are missing, it says "Till A saknas 1 A-poäng."
- **Feedback for a bare wrong number:** it is written in code, so the model can no longer claim a method the student never showed.
- **429:** the text is in Swedish.
