| (a) | **"Öva mer på":** `/study-cards` now also returns `practice`, 1–3 short areas where the student was unsure in the session (a wrong or "vet inte" answer, the same thing asked again, a request for a simpler explanation). With no clear sign, it returns the area that matters most for the exam. **This comes from the same call as the cards and the summary; there is no extra call.** | verified live |
| (b) | **"Lumen, förhör mig"** in Provläge (also "förhör mig", "ställ en kontrollfråga", "fråga mig något", "quiz me"): a note in the user message asks for ONE check question at the A level of the grade, about what was studied or, when nothing has been, what is likely on the exam ("På provet: …"). It follows the profile's style (ja–nej / korta / svåra), even when the profile says "inga kontrollfrågor". **In code:** this request is never silenced, and only the question itself is said (the last sentence that ends with "?"; lead-ins such as "Vi har inte pratat om något än, så …" or "Här är en fråga:" are dropped). **Grading:** when the last answer ended with a check question and the reply is short, the reply is graded first ("Rätt." / "Nästan." / "Inte riktigt."), then the correct answer in one sentence. | verified live |
| (c) | **Several exams:** the backend keeps no state between calls; the profile comes with each call (`persona_setup` for the chosen exam). The profile rules say that `<profile>` is the exam being studied now, and that other exams in `<memories>` must never be mixed into it. `/memory` updates an exam only within the same subject; a new subject is a new item. | verified live |

## Known limits and risks
- The grading note triggers on a short reply after an answer that ended with "?"; a short new question right after a
  check question can be graded as a reply.
- Without `recent_qa` / `already_asked`, the same quiz question can come twice.
