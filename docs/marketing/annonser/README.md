# Annonsbilder (Ke6)
Tre stillbilder 1080×1920 PNG (alla under 500 kB) för TikTok, Snapchat och Reels, med en `-skiss.png` per bild som visar textrutorna och den nedre säkra zonen (400 px). Aron väljer vilka som används.

| Bild | Rubrik | Fråga och svar (ordagrant ur D87-körningen, samma som på demosidan) | App-bild (T3, simulatorn) |
|---|---|---|---|
| `lumen-annons-1.png` | Bli förhörd inför provet | antibiotika och virus (pl-019) | start med prov |
| `lumen-annons-2.png` | Fråga i örat. Sikta på A-nivå. | Globalisering (pl-079) | Lägg till prov |
| `lumen-annons-3.png` | Plugga utan att titta på skärmen | näringskedja (pl-022) | Provläget lyssnar |

Källa: `_src/ad.html` (`?n=1|2|3`, `&skiss=1` för skissen), renderad med Chrome headless. Rubrik 2 säger "Sikta på A-nivå" och inte att svaret ger A, för det kan vi inte lova.
Ingen tidsangivelse, inga fuskpåståenden, ingen verklig person. App-bilderna är simulatorbilder, inte en riktig iPhone. Lägg `?utm_source=tiktok` m.fl. i länken, se `../lankar.md`.
