| D20 | 2026-11-03 | Accepted (Kevin) | Backend design (Supabase Edge Functions, `backend/`): (1) one streaming Claude call per request; the model's first line is a JSON header (`is_question`, `reconstructed_question`, `confidence`) followed by the answer text, parsed incrementally so `meta` is sent before any `delta`; (2) Haiku 5.5 called with `thinking: disabled`, `effort: low`, no sampling params, max 256 output tokens; (3) rate limits in Postgres (`check_rate_limit`, atomic fixed windows) with per-user minute/day caps and a global daily kill switch, all fail-closed; (4) JWT verified in-function (JWKS, optional HS256 secret) on top of gateway `verify_jwt`; (5) `/tts` is a pure ElevenLabs TTS proxy metered in characters; (6) transcripts/answers are never logged or stored, only usage metadata; (7) runtime deps pinned: `@anthropic-ai/sdk@1.3.0`, `jose@5.9.6`, `@supabase/supabase-js@2.45.4`. | Lowest time-to-first-token without a second call; zero-cost rule requires hard caps and fail-closed behaviour; privacy (R9). | D24 | 2026-11-03 | Accepted | **Activation (MVP item 3).** Default trigger is push-to-talk (hold the button; the words said while holding are the question; on release we wait up to 2 s for the recogniser's final result, else use the open partial). Auto mode runs a local scored `QuestionGate` on every final segment: question mark +0.6, interrogative start +0.55 (inside +0.2), imperative cue +0.5, maths pattern +0.6 (operator word + number, numbers normalised with `LumenScoring`), short fragment ≤3 tokens +0.35, statement start −0.3, >14 tokens −0.25; sensitivity = threshold low 0.7 / medium 0.5 / high 0.3; 8 s cooldown; nothing fires while our answer plays or for segments that overlapped playback. Manual "ask about the last sentence" and text entry share the path and have no cooldown. `ActivationRequest.trigger.backendMode` maps to the backend's `mode` (`push_to_talk`/`auto`/`text`). | ARCHITECTURE §6 stage 1 and Track D priority 1 (explicit activation first). Scores are explicit so the device session can tune them against the 30-prompt set and real classroom speech; the LLM classifier (stage 2) is the backend's `is_question` in auto mode. |
| D25 | 2026-11-03 | Accepted | **Answer engine client (MVP item 4).** `CloudAnswerProvider` talks to the deployed `/answer` function with an anonymous Supabase session (sign-up with the publishable key, JWT as bearer, refresh token kept in the Keychain, one automatic re-sign-in on 401). The publishable key is embedded in `BackendConfig` (public by design, grants nothing without a user JWT). Errors are surfaced verbatim (`code` + HTTP status) as a notice, `fallback:true` and offline set `wantsFallback` for the later on-device engine. One answer at a time: a new question cancels the running request. Context pack = last 60 s of final transcript (excluding our own playback) + last 3 Q/A + prep terms, clamped to the backend limits. A `MockAnswerProvider` (Debug toggle) replays deterministic answers for the Simulator and CI. | D19 (Claude via backend is the default), D20 (contract), zero-cost rule (no extra services), CLAUDE.md (no secrets in the app — the publishable key is not one). |
| D26 | 2026-11-03 | Accepted | **Voice output (MVP item 5).** `TTSProvider` chain: the chosen voice first (ElevenLabs via `POST /tts` with `output_format: pcm_24000`, streamed straight into the 24 kHz playback graph (D16) buffer by buffer), Apple's `AVSpeechSynthesizer` through the same graph as the always-available fallback and as a selectable voice. `Speaker` speaks answer sentences in order as they stream (`SentenceSplitter`), falls back to Apple for a sentence when the backend fails (quota, offline, 5xx), and a new question interrupts speech and clears the queue. Text > 500 chars is split at word boundaries (backend limit). `PlaybackService.isSpeaking` now stays true until scheduled audio has actually played (`.dataPlayedBack` completions), which is what self-playback suppression keys on. Voice/speed/"speak answers" persist in UserDefaults; the three premium voices come from `GET /voices` (D23) with a tolerant decoder until Kevin documents the exact shape; Apple-only until that endpoint is live. | D18 (ElevenLabs premium, Apple fallback), D23 (three voices + preview), item 5 "speak sentence by sentence, new question interrupts". PCM instead of MP3 avoids a decoder and gives the lowest time-to-first-audio. |
