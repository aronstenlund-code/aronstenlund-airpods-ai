| D20 | 2026-11-03 | Accepted (Kevin) | Backend design (Supabase Edge Functions, `backend/`): (1) one streaming Claude call per request; the model's first line is a JSON header (`is_question`, `reconstructed_question`, `confidence`) followed by the answer text, parsed incrementally so `meta` is sent before any `delta`; (2) Haiku 5.5 called with `thinking: disabled`, `effort: low`, no sampling params, max 256 output tokens; (3) rate limits in Postgres (`check_rate_limit`, atomic fixed windows) with per-user minute/day caps and a global daily kill switch, all fail-closed; (4) JWT verified in-function (JWKS, optional HS256 secret) on top of gateway `verify_jwt`; (5) `/tts` is a pure ElevenLabs TTS proxy metered in characters; (6) transcripts/answers are never logged or stored, only usage metadata; (7) runtime deps pinned: `@anthropic-ai/sdk@1.3.0`, `jose@5.9.6`, `@supabase/supabase-js@2.45.4`. | Lowest time-to-first-token without a second call; zero-cost rule requires hard caps and fail-closed behaviour; privacy (R9). Exact-version pins older than 10 days because Deno blocks very new releases (supply-chain policy). |
| D21 | 2026-11-03 | Accepted | **Consent and indicator (MVP item 1).** Consent is a versioned record (`ConsentRecord{version, grantedAt}`) stored locally in UserDefaults; `ConsentPolicy.currentVersion` is bumped whenever the consent text changes in substance, which re-shows the consent screen. `ListeningModel` refuses to start the microphone without a current record (not only the UI). The in-app listening indicator is rendered by `RootView` as a top safe-area bar above every screen while the session is listening or paused, with one-tap Stop/Resume. One `SessionController` owns the session state machine and the audio services; Listening and Diagnostics are two views of it. | ARCHITECTURE §12 / App Store guidelines: explicit consent + clear indication + one-tap stop.
